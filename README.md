# Retail Sales Analysis Using SQL

## Project Overview

This project analyzes retail sales data using SQL to uncover patterns in revenue, product performance, customer behavior, regional performance, and sales channels.

The analysis covers 2,000 sales orders and demonstrates the use of SQL for data validation, aggregation, business analysis, and advanced querying.

## Business Questions

This analysis explores the following questions:

- What is the company's overall sales performance?
- Which regions generate the most revenue?
- Which product categories contribute the most revenue?
- Which sales channels perform best?
- How do new and returning customers compare?
- Which products generate the most revenue?
- Which products perform best within each category?
- How does revenue change throughout the year?
- What percentage of total revenue comes from each product category?

## Key Performance Indicators

- **Total Revenue:** $2,452,084.30
- **Total Orders:** 2,000
- **Units Sold:** 5,552
- **Average Order Value:** $1,226.04

## Key Insights

- **Computers dominated revenue**, generating approximately $1.35M and contributing about 54.9% of total revenue.
- **Accessories recorded the highest unit sales**, despite generating substantially less revenue than Computers.
- **Online sales generated the highest total channel revenue** at approximately $791.5K.
- **Corporate Sales had the highest average order value** at approximately $2,158 per order, indicating fewer but higher-value transactions.
- **Returning customers generated approximately $1.68M**, accounting for about 69% of total revenue.
- **November recorded the highest monthly revenue**, at approximately $274.4K.
